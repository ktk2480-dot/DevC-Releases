# 개발부담금 산정 프로그램 (DevC) — 설치파일

이 저장소는 **설치파일 배포용**입니다(프로그램 소스는 들어 있지 않습니다).
프로그램을 쓰려면 구입처에서 발급하는 **인증키**가 필요합니다.

## 사용 환경

- Windows 10 / 11 (64비트)
- 인터넷은 설치·인증에는 필요 없습니다. 공공 데이터 조회, AI 기능, 새 버전 알림에 씁니다.

## 설치

1. 위의 설치파일을 내려받습니다.
   - 브라우저에 "일반적으로 다운로드되지 않는 파일" 경고가 나오면 **[⋯] → [유지]** 를 누르세요.
2. 내려받은 파일을 실행합니다.
   - **"Windows의 PC 보호"** 창이 나오면 **[추가 정보] → [실행]** 을 누르세요.
   - 아직 코드서명 인증서가 없어 나오는 안내입니다.
3. 설치 방식을 고릅니다.
   - **모든 사용자**: 관리자 권한이 필요합니다.
   - **현재 사용자만**: 관리자 권한 없이 설치됩니다.
4. 설치가 끝나면 시작 메뉴의 **개발부담금 산정 프로그램** 을 실행합니다.

## 인증 (처음 한 번)

1. 프로그램 왼쪽 메뉴 **[라이선스]** 를 엽니다.
2. **① 인증 요청키 생성** 에서 [요청키 생성] → [복사] 를 누릅니다.
3. 복사한 요청키를 구입처 담당자에게 메일이나 메시지로 보냅니다.
4. 받은 인증키를 **② 인증키 등록** 에 붙여넣고 [인증키 등록] 을 누릅니다. `.lic` 파일로 받았다면 [인증키 파일 선택] 을 쓰세요.

- 인증 전에는 **읽기 전용** 입니다. 샘플 프로젝트를 보고 내보낼 수 있습니다.
- 인증키는 그 PC에서만 쓸 수 있습니다. PC를 바꾸면 새 PC에서 요청키를 만들어 재발급을 요청하세요.

## 새 버전

- 새 버전이 나오면 프로그램을 시작할 때 알려 줍니다(하루 한 번). 자동으로 설치하지는 않습니다.
- 새 설치파일을 그대로 설치하면 됩니다. **프로젝트·인증·설정은 그대로 남습니다.**
- 설치 중 "프로그램을 닫으세요" 가 나오면 프로그램을 닫고 다시 설치하세요.

## 제거

- Windows **설정 → 앱** 에서 "개발부담금 산정 프로그램" 을 제거합니다.
- 작업 자료(`%LOCALAPPDATA%\DevC`)는 지워지지 않습니다.
- 자료까지 지우려면 먼저 [프로젝트 내보내기]로 백업한 뒤 그 폴더를 삭제하세요.
